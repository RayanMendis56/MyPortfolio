# Personal Portfolio

A responsive personal portfolio website for presenting my background, education, experience, technical skills, projects, certifications, and contact information.

## Features

- Responsive layout for desktop and mobile screens
- Hero section with quick links to portfolio sections
- Education and experience cards
- Technical skills, project gallery, and certifications
- Contact form layout

## Built With

- HTML
- CSS
- JavaScript
- Google Fonts (Poppins)
- Font Awesome icons

## Run Locally

This is a static website and does not require a build step.
Python 3 is only needed if you want to run the local web server below.

1. Clone the repository:

   ```bash
   git clone https://github.com/RayanMendis56/MyPortfolio.git
   ```

2. Open the project directory:

   ```bash
   cd MyPortfolio
   ```

3. Start a local web server:

   ```bash
   python3 -m http.server 8000
   ```

4. Visit [http://localhost:8000](http://localhost:8000) in your browser.

## Customization

- Update section content and links in `index.html`.
- Adjust the layout and styling in `assets/css/style.css`.
- Replace or add images in `assets/images/` and update their paths in the HTML.
